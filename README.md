# Phase Shift

A retro-style 2D platform game made with Python and Pygame.

In Terminal, first go to the project folder, then start the game:

```bash
cd /phase-shift
.venv/bin/python client/main.py
```

The `client` folder contains the launch point. The `game` folder contains the
game code and `requirements.txt`. Existing starter files have been left in place.

## Controls

- Move: `A` / `D` or Left / Right arrows
- Charge a jump: hold `Space` while standing, then release
- Create a temporary platform: `E`
- Restart after winning: `R`
